# Employee Attendance Anomaly Detection

**Author:** Sandra Otubushin
**Date:** 2026-10

## Project Overview

This project identifies unusual employee attendance patterns. It uses Python and Polars to analyze scheduled hours, worked hours, late days, and absence days.

The goal is to identify employee records that may need additional review.
