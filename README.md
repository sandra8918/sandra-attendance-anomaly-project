# Employee Attendance Anomalies

> Detect unusual employee attendance records using Python and rule-based anomaly detection.

## Project Purpose

This project analyzes employee attendance records and identifies unusual patterns, including excessive absences, missing attendance information, and attendance outside the expected range.

## Author

Sandra Otubushin

## Date

## Project Goal

The goal of this project is to demonstrate how analytics tools can be used to identify possible data-quality issues and unusual attendance patterns.

## Tools

This project uses Python, Polars, pytest, Ruff, uv, Git, and GitHub.
